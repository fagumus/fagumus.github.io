# Fatma Gümüş — Academic Website

A lightweight, responsive academic website for GitHub Pages. No build tools or hosting fees required.

## Publish to GitHub Pages

1. Sign in as **fagumus** and create a **public** repository named **`fagumus.github.io`**.
2. Upload **the contents of this folder** (not the enclosing folder) to the repository root. Keep `index.html` at the root.
3. Open repository **Settings → Pages → Build and deployment**, select **Deploy from a branch**, branch **main**, folder **/(root)**, and Save.
4. Once deployment finishes, visit **https://fagumus.github.io**.

## Update publications

Edit `data/publications.json`. Each item has `text` and `url` fields. The website automatically renders all journal publications and selected conference papers.

## Update profile

Edit `index.html` for research interests, biography, contact details, and section text. Update `assets/Fatma_Gumus_CV.docx` when your CV changes.

## Before publishing

- The NoisyBox paper is listed as accepted with an anticipated publication date of 22 October 2026. Replace this with its final publication details and DOI once available.
- Verify every bibliographic record against the journal/publisher pages.
- Add Google Scholar and ORCID URLs only after confirming the correct profile addresses.
- Optionally replace the monogram with a professional photo that you own or have permission to use.

The design intentionally avoids frameworks and external JavaScript dependencies. Google Fonts are optional; the site remains functional if they are unavailable.
